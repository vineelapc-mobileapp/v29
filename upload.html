Student Marks — Not Available Yet

Each student's test history currently lives only on their own phone/laptop (see "My Test History" in the student app) — there's no server for their device to send scores to, so this tab can't show them yet.

To make this real, the app needs a small backend (Firebase is the practical option — free tier, works well with this kind of app) that every student's device writes scores to, and this tab reads from. That's a genuine architecture change, not just a new screen — let your teacher-assistant know if you want to take that step and it can be built as the next version.

Student Doubts — Not Available Yet

Same underlying reason as Student Marks: a message (with voice, photo, PDF, or text) from a student's device needs somewhere to land that your device can then read and reply to. That requires the same backend (Firebase) mentioned in the Marks tab — once that's in place, this tab and the marks tab can be built together, since they'd share the same underlying setup.
